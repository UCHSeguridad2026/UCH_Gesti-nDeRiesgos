
# Usuarios y Roles - SimpleRisk

| Usuario | Rol | Permisos principales |
|---|---|---|
| admin_clinica | Administrador | Control total del sistema, gestión de usuarios y configuración |
| analista_clinica | Analista de Riesgos | Crear, modificar y evaluar riesgos; planificar medidas de mitigación; comentar riesgos |
| auditor_clinica | Auditor (solo lectura) | Acceso de visualización a Gestión de riesgos y Cumplimiento; puede comentar |
