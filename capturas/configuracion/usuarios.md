# Configuración de Usuarios y Roles en SimpleRisk

Se configuraron tres usuarios con roles diferenciados para cumplir con el control de acceso y privilegios mínimos:

1. **admin_demo** (Rol: Administrator)
   - *Permisos:* Control total de la plataforma, configuración global y gestión de riesgos.
2. **analista_riesgos** (Rol: Risk Manager)
   - *Permisos:* Creación, evaluación y seguimiento de riesgos y planes de mitigación.
3. **auditor_sistema** (Rol: Auditor)
   - *Permisos:* Acceso de solo lectura para revisión de registros y reportes.

*Nota:* No se incluyen credenciales ni contraseñas en este repositorio por normativas de seguridad[cite: 3].
